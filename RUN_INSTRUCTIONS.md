User requirements (summary):
- A system like "Stockfish" for American football: evaluate plays given full rosters, traits, and field situations.
- Support full 22-player assignments per play; unique player settings and switching between offense/defense.
- Allow setting down and distance and other `FieldState` variables.
- Analysis engine: hybrid rules + ML, producing explanations and scores for plays.
- Web UI: roster editor, field canvas where users can drag players, draw routes, move players like a whiteboard.
- Play library: pre-generated formations/plays, import/export, ability to draw new plays and have the model detect or create concepts and compute success rates.

  - Docker-ready: `backend/Dockerfile`, `backend/docker-compose.yml` (includes `db`, `api`, and `frontend` services)

Run instructions (Docker, recommended — no local Node required):

1) Build and start services (Postgres, API, frontend Vite):

```powershell
cd backend
docker-compose up --build
```

This will:
- start Postgres on port 5432 (service name `db`)
- build and run the API service on port 4000
- build and run the frontend Vite dev server on port 5173

2) Seed sample players (after services are up):

```powershell
cd backend
docker-compose run --rm api npm run seed
```

3) Run backend tests (TypeScript build + test runner):

```powershell
cd backend
docker-compose run --rm api npm run test
```

4) API quick checks (after docker-compose up):

```powershell
curl http://localhost:4000/api/v1/health
curl http://localhost:4000/api/v1/players

# analyze sample payload
curl -X POST http://localhost:4000/api/v1/analyze -H "Content-Type: application/json" -d "{\"field_state\":{\"down\":2,\"distance\":6},\"roster_id\":null,\"play_instances\":[{\"id\":\"pi1\",\"actions\":[{\"player_id\":\"p3\",\"route\":[{\"x\":100,\"y\":50},{\"x\":300,\"y\":50}]}]}]}"
```

5) Frontend:

- Visit: http://localhost:5173
- Drag players from the roster into the field, switch to Draw mode to add route points (click to create points), then use `Save Play`, `Analyze`, or `Identify Concept` buttons.
